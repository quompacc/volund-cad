# U07 – New/Open/Save und Close-Schutz in der Shell

**Status:** abgenommen am 06.10.2026 nach grünem CI-Lauf 432 (`80471e7`).

## Bestand

Die meisten Teile gab es schon aus der Shell-Arbeit und `desktop.document_actions`:
- Save/Discard/Cancel vor Neu, Öffnen und Duplizieren.
- Ein fehlgeschlagenes Speichern bricht den Folgeschritt ab.
- Ein fehlerhaftes Öffnen behält das aktive Dokument.
- Speichern unter setzt den Titel erst nach Erfolg.
- Unicode-Dateinamen funktionieren.

## Geschlossene Lücken

- **Dateiargument:** `voelund-cad datei.volund`, z. B. aus der Dateizuordnung des
  Desktops, öffnet über denselben sicheren Weg wie Datei → Öffnen
  (`DocumentActions::openFile`, `MainWindow::openFile`). Ein Fehler zeigt seine Meldung
  und behält das neue Dokument.
- **`desktop.document_guards`** (echtes Hauptfenster):
  - Neu: Abbrechen erhält das Modell; Speichern speichert und legt dann neu an.
  - Schließen: Abbrechen hält das Fenster offen; ein fehlgeschlagenes Speichern hält es
    offen; Verwerfen schließt.
  - Eine defekte Datei als Argument behält das aktive Dokument samt Titel.
  - Getestet im Ordner `Prüfung mit Leerzeichen/Teil äöü.volund`.
