# M25 – Formschräge

**Status:** abgenommen am 14.10.2026 nach grünem CI-Lauf 593 (`82d80b6`).

## Entscheidungen (ohne Rückfrage, Nutzerauftrag vom 14.10.2026)

- **Eigener Feature-Typ `draft`** („Formschräge N“): Körper, zu neigende Flächen (1 bis 256),
  neutrale ebene Fläche, Winkel (betragsmäßig unter 90°).
- **Zugrichtung in den Körper hinein** (gegen die äußere Normale der neutralen Fläche): Ein
  positiver Winkel verjüngt den Körper von der neutralen Fläche weg, wie eine
  Entformungsschräge. Negative Winkel weiten.
- **Flächen:** über ihre Namen auf dem Körper vor der Formschräge gefunden; sie behalten ihre
  Namen (Historie des Kernels).
- **Abweisungen:**
  - Eine Fläche, die der Kernel nicht neigen kann, meldet `draft-face-refused` mit ihrer Nummer.
  - Eine fehlende Fläche meldet `draft-face-missing`.
  - Eine fehlende neutrale Fläche meldet `draft-neutral-missing`.
- **Bedienung:**
  - `solid.modify.draft` mit gewählter ebener Fläche: Sie ist die neutrale Fläche.
  - Klicks auf weitere ebene Flächen (auch auf der Vorschau) neigen sie oder nehmen sie
    zurück.
  - Panel: Winkel, „Geneigte Flächen zurücksetzen“, „Neutrale Fläche neu wählen“.
  - Bearbeiten und Zeitleiste öffnen es wieder.
- **Schema 29.**

## Änderung

- **Kernel:** `DraftOperation.cpp` (`BRepOffsetAPI_DraftAngle`) mit `DraftFaceError`. Die
  Historie nimmt geneigte Flächen über `ModifiedShape()`, weil `Modified()` sie nicht meldet.
  So bleiben alle Flächen benannte ebene Flächen, etwa für eine spätere Skizze.
- **Dokument:** `DraftParameters`, `ModelDocumentDraft.cpp`, Codec `NativeDraft.cpp`,
  Körperzuordnung wie die Wandstärke.
- **Auswertung:** `DraftEvaluation.cpp`.
- **Anwendung:** `createDraft`, `editDraftParameters`, Aktionen `CreateDraftAction` und
  `EditDraftParametersAction`; MCP-Kontext mit Winkel, Körper und Flächenzahl.
- **Oberfläche:** `DraftToolController`, Befehl, Symbol, Zeitleiste.

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Vier Quaderseiten 5° auf der Grundfläche: Volumen analytisch (∫(40−2tz)(30−2tz)dz); alle sechs Flächen bleiben benannt | `application.draft` |
| 10°: folgt; Rückgängig | ebenda |
| Deckfläche (parallel zur neutralen Ebene): abgewiesen mit `draft-face-refused` und Nummer 1 | ebenda |
| Speichern/Öffnen | ebenda |
| Oberfläche: Deckfläche neutral → Vorderseite neigen, auf der Vorschau zurücknehmen, wieder neigen → 10° → OK „Formschräge 1“ → Rückgängig | `desktop.draft_panel` |

## Grenzen

- Keine Trennlinien-Formschräge (Paketgrenze).
- In der Oberfläche lassen sich nur ebene Flächen anklicken; das Dokument nimmt auch andere
  benannte Flächen.
