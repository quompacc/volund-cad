# V01a – Basisebenen, Skizze ohne Körper, Extrusion als neuer Körper

**Status:** abgenommen am 04.10.2026 (Teil von V01, ohne UI).

## Umsetzung

- `document::DatumPlane` (XY, XZ, YZ) mit festen Rahmen: XY Normale +Z; XZ x entlang
  +X, Skizzen-y entlang +Z, Normale −Y; YZ x entlang +Y, Skizzen-y entlang +Z,
  Normale +X. `SketchParameters::datum` ist genau dann gesetzt, wenn die Skizze kein
  Stützfeature hat. Die Ebene muss exakt der Basisebene entsprechen; Bindung und
  Reparaturgrund sind ausgeschlossen.
- `ModelDocument::addDatumSketchFeature`, `CadSession::createDatumSketchFeature`,
  `SketchEditorSession(session, DatumPlane)` sowie ein Bearbeitungskonstruktor für
  Basisebenen-Skizzen.
- Körperidentität: Eine Basisebenen-Skizze eröffnet einen Körper mit BodyId = ihre
  FeatureId. Damit bleibt die Regel „BodyId = erzeugendes Feature“ aus D11 erhalten.
  Ihre Extrusion erzeugt dessen ersten Volumenkörper ohne Vereinigung; ein zweiter
  Volumenkörper desselben Körpers wird abgewiesen.
- Natives Schema 6: optionales Skizzenkind 13 (Basisebene) und kein Eingangsverweis
  (Kind 5); beides nur ab Schema 6. Die Körpergruppe der Skizze ist ihr eigener Körper.
  Schema 1–5 lesen unverändert.
- Beim Öffnen werden Basisebenen-Skizzen nicht als `legacySupport` markiert.

## Grenzen

- Keine UI; die Viewport-Ebenen folgen in V01b und werden vorher zur Durchsicht vorgelegt.
- Nur ein Volumenkörper je Basisebenen-Skizze; Join/Cut gegen andere Körper bleiben
  M02–M04.
- Eine Skizze auf einer Fläche eines Basisebenen-Körpers ist über die bestehende
  Bindung möglich, aber noch nicht eigens abgenommen.
