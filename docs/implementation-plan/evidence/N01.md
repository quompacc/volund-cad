# N01 – Ausdrücke und Parameter in allen Maßfeldern

**Status:** Teil N01a (Ausdrucksauswerter, Parameter als Ausdrücke, Schema 37, Oberfläche) mit
Code und Prüfungen vom 21.10.2026. Teil N01b (Bindung in allen übrigen Maßfeldern) folgt; erst
danach ist N01 abgenommen.

## Entscheidungen (Nutzer, 21.10.2026)

- **Rechnen und Funktionen:**
  - Rechenzeichen: + − × ÷ ^ und Klammern.
  - Einheiten: mm, cm, m, in, °, deg, rad.
  - Funktionen und Konstanten: sqrt, sin, cos, tan, abs, min, max, round und pi.
  - Es gibt keine fremde Skriptsprache.
- **Parameter als Ausdrücke:** Ein Parameter darf selbst ein Ausdruck sein, zum Beispiel
  B = A*2 + 4. Zyklen werden mit ihrem Pfad abgewiesen („Zyklus: A → B → A“).
  Persistiert wird das in Schema 37.

## Änderung (N01a)

- **Auswerter** (`ParameterExpression`):
  - Ein eigener Lexer und ein Parser mit rekursivem Abstieg.
  - Einheiten werden nach ihrer Dimension (Länge oder Winkel) geprüft. Eine Zahl ohne Einheit
    gilt in der Einheit des Feldes.
  - Fehler werden mit Position gemeldet: unbekannter Name, gemischte Dimension, Division durch
    null, Syntax.
  - Höchstens 1024 Bytes je Ausdruck.
- **Dokument:**
  - `DocumentParameter::expression` speichert den Ausdruck.
  - `ParameterUnit::number` ist die neue reine Zahl, zum Beispiel für Anzahlen.
  - `resolveParameterTable` rechnet in Abhängigkeitsreihenfolge und erkennt Zyklen.
  - Beim Prüfen muss jeder gespeicherte Wert gleich dem Wert seines Ausdrucks sein.
- **Session:**
  - `setParameterExpression` setzt einen Ausdruck. `setParameterValue` ersetzt einen Ausdruck
    durch die getippte Zahl.
  - Jede Änderung rechnet die abhängigen Parameter neu und spiegelt sie in alle Bindungen, in
    einem Rückgängig-Schritt.
  - Umbenennen schreibt die Ausdrücke um, die den Namen benutzen.
  - Löschen ist gesperrt, solange ein Ausdruck den Parameter benutzt.
- **Speichern:**
  - Schema 37: Kind 6 des Parametereintrags enthält den Ausdruck; die Einheit 3 ist die reine
    Zahl.
  - Ältere Schemas lehnen beides ab. Schema 1–36 bleiben lesbar.
- **Oberfläche:**
  - Ein Maßfeld nimmt „=Ausdruck“ an. Ein Ausdruck, der kein reiner Name ist, legt nach der
    Rückfrage den Parameter „AusdruckN“ an und bindet das Feld an ihn.
  - Die Tabelle zeigt „=Ausdruck → Wert“. Eine Zelle, die mit „=“ beginnt, setzt den Ausdruck.
  - Was abgewiesen wird, nennt die Statuszeile mit Grund.

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Rechenregeln, Vorrang, Potenz rechtsassoziativ, Einheiten und Umrechnung, Funktionen, pi; Fehler mit Position; Namen sammeln und umbenennen | `document.parameter_expressions` |
| B = A*2 + 4 folgt A, die gebundene Extrusion folgt; Zyklus mit Pfad und unbekannter Name abgewiesen; getippte Zahl ersetzt den Ausdruck; Rückgängig; Umbenennen schreibt um; Löschen gesperrt; Speichern/Öffnen | `application.parameter_expressions` |
| Schema 37: Ausdruck und reine Zahl im Rundlauf; Schema 36 lehnt beides ab; ein abweichender gespeicherter Wert wird abgelehnt | `document.native_parameters` |
| „=10*2“ im Extrusionsfeld legt nach Rückfrage „Ausdruck1“ an (Tiefe 20); die Tabelle zeigt „=10*2 → 20“; „=A*3“ in der Tabelle ergibt Tiefe 15; „=Q*2“ wird mit Grund abgewiesen | `desktop.expression_flow` |

## Grenzen (bis N01b)

- Gebunden werden bisher nur Skizzenbemaßungen und die Extrusionstiefe (PAR01/PAR02). Bohrung,
  Verrundung, Fase, Muster, Grundkörper, Drehen, Wandstärke, Formschräge, Bezugselemente,
  Bewegen und Push/Pull folgen mit N01b.
