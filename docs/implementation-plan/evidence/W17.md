# W17 – Skizze lesbar auf jedem Bildschirm

**Status:** abgenommen (in main, CI grün; Nachtrag 30.10.2026).

Auslöser: Nutzer-Rückmeldung vom 25.10.2026 (Bildschirmfoto, 200 %-Bildschirm): „Die Schrift
ist extrem klein.“

## Befund

OCCT zeichnete Maßzahlen, Beziehungsbeschriftungen, Punktmarken und Linienbreiten in
Framebuffer-Pixeln. Die Ansicht kannte die Bildschirmskalierung nicht (`RenderingParams.Resolution`
nie gesetzt); auf einem 200 %-Bildschirm war alles halb so groß wie gedacht. Ein Bildschirmfoto
auf Fedora mit `QT_SCALE_FACTOR=2` zeigte dasselbe: Panels groß, „60 mm“ und „[H]“ winzig.

## Entscheidungen (Agent, 25.10.2026)

- Die Ansicht setzt `Resolution = 72 × Skalierung` (bei 100 % unverändert), beim Start und
  wenn das Fenster auf einen anderen Bildschirm wechselt.
- Eigene Pixelmaße der Skizzenbeschriftung (Abstand zum Anker, Stapelung, Maßpfeile,
  Trefferfläche) werden mit derselben Skalierung multipliziert.
