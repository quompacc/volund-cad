# V01b – Basisebenen im Viewport

**Status:** umgesetzt am 04.10.2026. Die Nutzerdurchsicht der Aufnahmen steht aus.
Abgenommen wird nach der Freigabe.

## Umsetzung (Nutzerentscheidungen vom 04.10.2026)

- XY, XZ und YZ als halbtransparente Quadrate durch den Ursprung: XY blau, XZ grün,
  YZ rot, Rahmen dieselben Farben. Ihre Rahmen entsprechen `document::datumSketchPlane`.
- Leeres Dokument: deutlich sichtbar. Neben Körpern: sehr dezent, weiter anwählbar;
  Hover zeigt sie halbtransparent orange. Beim Skizzieren ausgeblendet.
- Hover und Auswahl der Ebenen sind halbtransparent (orange beziehungsweise blau),
  damit das Modell dahinter sichtbar bleibt.
- Klick auf eine Ebene wählt sie. Die Statuszeile meldet „XY plane selected“, „Sketch“
  wird aktiv und startet den Skizzeneditor auf der Ebene (Kamera senkrecht).
  OK legt eine Basisebenen-Skizze an (V01a). Vorhandene Basisebenen-Skizzen lassen
  sich mit „Edit Sketch“ wieder öffnen.
- Ein Klick auf eine Körperfläche hebt die Ebenenwahl auf und umgekehrt.

## Prüfungen

  Hover, Klick wählt XY, „Sketch“ wird aktiv und startet den Editor, Ebenen

- Aufnahmen für die Durchsicht: `artifacts/v01b-review/` (leer, Hover, Auswahl,

  Viewport wurde vor dem Commit behoben.

## Bewusst offen (UX01 / S03)

- Keine 3D-Beschriftung XY/XZ/YZ: Die Windows-Ausgabe von OCCT findet keine Schrift.
  Ob Beschriftungen gewünscht sind, wird in UX01 entschieden.
- Die Kamera kehrt nach dem Abbruch einer Skizze nicht in die vorige Ansicht zurück
  (Rückkehrkamera in S03).
- Die Namen der Befehlsbedingungen (`canEditSketch` für „Sketch“) sind verwirrend und
  werden mit der neuen Oberfläche bereinigt.
