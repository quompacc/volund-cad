# N16 – Programmsymbol

**Status:** abgenommen am 21.10.2026. Code `c4bd5eb`; CI-Lauf 703 grün.

## Änderung

- **Symbol:** Das Ambosszeichen der Kopfleiste auf der Tintenfarbe des Themes, mit Funke in
  Akzentfarbe. Kein neues Gestaltungskonzept. Quelle `packaging/icons/voelund-cad.svg`, daraus
  PNG 256 und ICO (16–256 px), Erzeugung in `packaging/icons/README.md`.
- **Windows:** Ressource `IDI_ICON1` in der EXE (`apps/voelund-cad/voelund-cad.rc`) für
  Explorer, Taskleiste und Dateizuordnung (`DefaultIcon` zeigt auf die EXE).
- **Fenster:** `QGuiApplication::setWindowIcon` aus der Qt-Ressource beim Produktstart.
- **Linux:** SVG und PNG unter `share/icons/hicolor/{scalable,256x256}/apps` mit dem Namen des
  Desktop-Eintrags. Dort steht jetzt `Icon=io.github.quompacc.Voelund` statt des
  Systemsymbols. `install-user.sh` kopiert die Symbole nach `XDG_DATA_HOME`,
  `uninstall-user.sh` entfernt sie.
- **Paket:** Die Symboldateien gehören zur Komponente `voelund` (`packaging/Components.cmake`).

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Fenstersymbol gesetzt, 256 px vorhanden | `desktop.product_arguments` (Fedora) |
| Symbole pro Nutzer installiert, `Icon=` richtig, nach Deinstallation entfernt | `desktop.file_association` (Fedora) |
| Jede Paketdatei einer Komponente zugeordnet, Manifest stimmt | `platform.package_runtime` (Fedora, Windows) |
| Symbol in Titelleiste und Taskleiste des Release-ZIPs auf frischem Windows | Windows Sandbox (`Start-WindowsSandboxCheck.ps1`), Bildschirmfoto angesehen |
| Symbol bei 32 px erkennbar | Rasterbild angesehen |
