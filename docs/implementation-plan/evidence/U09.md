# U09 – Input und Drag als eine Benutzeraktion

**Status:** abgenommen am 07.10.2026 nach grünem CI-Lauf 436 (`e387583`).

## Ausgangslage

- Der Verlauf des Skizzeneditors wurde bei jedem Neuzeichnen festgeschrieben. Beim Ziehen
  ergab deshalb jede Mausbewegung einen eigenen Undo-Schritt.
- Escape während des Ziehens schloss den ganzen Editor.
- Jede Wertänderung im Feld „Gewählt ΔX/ΔY“ war ein eigener Schritt.

## Änderung

- **`SketchEditorSession`:** Ziehen ist eine Transaktion.
  - `beginDrag` merkt sich den Startzustand.
  - `dragSelected` verschiebt den Kandidaten vom Start um den Gesamtversatz.
  - `endDrag` schreibt genau einen Schritt.
  - `cancelDrag` stellt den Start wieder her.
  - Solange gezogen wird, schreibt `commitHistory` nichts.
- **Viewport:** Das Loslassen nach dem Ziehen eines Elements meldet sich an der Shell;
  `cancelSketchElementDrag` beendet ein Ziehen bei Escape.
- **Controller:**
  - Ziehen mit der Maus und getippte Verschiebung (bis „Bearbeitung beendet“) nutzen
    dieselbe Transaktion.
  - Escape während des Ziehens stellt den Start her; der Editor bleibt offen.
  - Eine neue Auswahl oder OK schließt eine laufende Verschiebung als eigenen Schritt ab.
  - Die Logik liegt in `SketchEditorDrag.cpp`.
- **Werkzeugpanel:** `ToolPanelDefinition::parameterFinished` meldet das Ende einer
  Längeneingabe.

## Prüfungen

- **CI-Lauf 436:** grün.
- **Windows:** 125/125.
- **Fedora (GCC):** Build sauber, 91/91 ohne Desktop.
- **`desktop.sketch_drag` (A-TXN-03):**
  - 100 Bewegungen und Loslassen ergeben einen Undo-Schritt; Redo wiederholt ihn.
  - Escape während des Ziehens bringt den Ausgangszustand zurück, der Editor bleibt aktiv,
    es entsteht kein Schritt.
  - Zweimal Neuzeichnen ergibt keinen Schritt.
  - Drei getippte Werte bis zum Ende der Eingabe ergeben einen Schritt.
- Das Ziehen von Körpern mit dem Manipulator war schon eine Transaktion je Ziehen.

## Grenzen

- Der Verlauf wird außerhalb des Ziehens weiterhin beim Neuzeichnen festgeschrieben;
  wegen des Gleichheitsvergleichs entsteht dabei ohne Änderung kein Schritt.
- Ziehen verschiebt wie bisher nur das gewählte Element oder den gewählten Punkt. Das
  Verschieben mehrerer Elemente gehört zu S08.
- Es gibt keine Pfeiltasten-Verschiebung; sie ist nicht vorhanden und wurde nicht neu
  eingeführt.
- Der Manipulator für Körper hat keinen Abbruch mit Escape.
