# L03 – Release-Metadaten und Upgradepfad

**Status:** abgenommen am 18.10.2026 – Code `c7fc933`; CI-Lauf 684 grün.

## Entscheidung

- **Nutzer, 18.10.2026:** „Über Völund…“ als Eintrag im Hauptmenü (≡), nicht in der
  Befehlssuche.

## Änderung

- **Version aus einer Quelle:**
  - `tools/cmake/WriteBuildInfo.cmake` schreibt bei jedem Build `voelund/BuildInfo.hpp` mit
    Version (`PROJECT_VERSION`), Git-Revision (`git describe --always --dirty`) und Build-Typ.
    Die Datei wird nur bei Änderung neu geschrieben.
  - Dieselbe Version tragen CPack-Paket, `QCoreApplication::applicationVersion` (bisher
    hartkodiert „0.1.0“), `--version` und „Über Völund“.
- **„Über Völund…“** (`AboutDialog.cpp`): letzter Eintrag im Hauptmenü, Befehls-ID `app.about`.
  - Inhalt: Version, Revision, Build, Dokumentformat (Schema 36; liest ältere Schemata und
    VOLUND 1–16), OpenCASCADE, Qt (Laufzeit und Build), Plattform, Darstellung,
    Einstellungsdatei, Wiederherstellungsordner.
  - „Diagnose kopieren“ legt den ganzen Text in die Zwischenablage.
  - Neu ist der öffentliche Zugang `document::nativeDocumentSchema()`.
- **Verständliche Ablehnung beim Öffnen** (`DocumentErrorText.cpp`):
  - neueres Format → „Die Datei stammt aus einer neueren Völund-Version …“;
  - fremdes Format, beschädigte Datei und Sonstiges jeweils mit eigenem deutschen Satz.

  Die technische Meldung folgt immer in Klammern.
- **Befehlszeile ohne Fenster** (`apps/voelund-cad/CommandLine.cpp`):
  - `--version`;
  - `--check-document <datei> [--resave <ziel>]`: öffnet mit dem Produktleser, speichert auf
    Wunsch neu und öffnet die Kopie wieder.

  So lässt sich auch das installierte Programm ohne GUI-Test prüfen.
- **Upgrade- und Deinstallationsregeln** in [packaging.md](../../packaging.md).

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Installiertes Programm meldet die Paketversion | `platform.package_runtime`, `platform.version` |
| Installiertes Programm öffnet VOLUND 1 und 16, speichert neu (aktuelles Schema) und öffnet die Kopie | `platform.package_runtime` |
| „VOLUND 99“: Exit 2, „Die Datei stammt aus einer neueren Völund-Version …“ | ebenda |
| Erneutes Installieren und Entfernen des Paketordners ändern ein Nutzerdokument nicht (SHA-256) | ebenda |
| „Über Völund…“ ist der letzte Menüeintrag; Inhalt; „Diagnose kopieren“; `applicationVersion` = Build-Version | `desktop.about_dialog` |
| Befehlstabelle enthält `app.about` (immer aktiv) | `desktop.command_inventory`, `docs/ui-concept.md` |

## Grenzen

- **Native Dokumente aus der Zukunft:** Die Ablehnung eines höheren nativen Schemas prüfen die
  Dokumenttests (`document.native_metadata`). Der Pakettest nutzt dafür das Textformat
  „VOLUND 99“.
- **Einstellungen beim Upgrade:** Sie liegen außerhalb des Paketordners, ihr Erhalt folgt aus
  dieser Ablage und ist nicht eigens gemessen.
- Ohne Git zum Build-Zeitpunkt lautet die Revision „unknown“.
