## Ziel (README)

Eine produktive Oberfläche: neues Dokument → Ebene → Skizze → echte Extrusion → Änderung →
Speichern → Öffnen. Alle sichtbaren aktivierten Befehle funktionieren über denselben
Anwendungskern.
