# R10 – Regionen zu validen Kernel-Faces (V01-Umfang)

**Status:** abgenommen am 04.10.2026 für verschachtelte, nicht schneidende Konturen.
Schneidende Anordnungen folgen als R10b nach V01.

## Umsetzung

- `evaluateRegionFaces` ist der produktive Face-Weg für Regionsauswahlen. Er wurde in
  R09b als Brücke eingeführt: Außenrand und Löcher sind ganze Schleifen, die Löcher werden
  zu Innenwires mit geometrisch gewählter Orientierung. Jede Fläche wird mit BRepCheck
  geprüft, ihr Inhalt muss genau Außenfläche minus Löcher sein. Eine mitgewählte
  Innenregion füllt das Loch des Elternrings.
- Fehler nennen jetzt die betroffenen Elemente: entfernte Randelemente, die Elemente
  eines geteilten oder mehrdeutigen Randes, die R08b-Diagnoseelemente einer ungültigen
  Skizze und die Elemente einer schneidenden Anordnung. Eine Regionsauswahl liefert nie
  eine leere Erfolgsform; jede gewählte Region erzeugt eine Fläche oder einen Fehler.

## A-REG-01 (`features.sketch_region_faces`)

| Fall | Ergebnis |
|---|---|
| Rechteck, Line/Arc-Rand (Halbkreis plus Durchmesser), Ellipse | gültige Fläche, 40 / 2π / 8π |
| zwei getrennte Rechtecke | zwei Flächen, zusammen 22 |
| konzentrische Kreise R20/r10 | Ring 300π mit 2 Wires; Innenregion separat 100π; beide gewählt: eine Fläche 400π |
| drei verschachtelte Kreise | äußerer Ring und innerste Scheibe getrennt, 3 Wires, 325π |
| Permutation, umgedrehte Linie, nicht monotone IDs, Konstruktion durch die Region | gleiche Fläche |
| Toleranzmatrix | Ring mit r = 0,002 und 100 000 bei Versatz 300 000 |
| Überlappung, Tangentialkontakt, entferntes Element, Selbstschnitt | Fehler mit Element-IDs |

Offene Konturen und T-Verzweigungen bilden seit R09c keine Materialgrenze und keinen
Skizzenfehler (K07). Abgedeckt ist das in `features.sketch_regions`.

## Grenzen

- Zellen schneidender Konturen (Linse, Sicheln, Bow-Tie, Sehnenhälften) werden mit
  Elementangabe abgewiesen → R10b.
