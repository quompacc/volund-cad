# U15 – Fehlermeldungen in der Oberfläche auf Deutsch

**Status:** abgenommen am 18.10.2026. Code `e718d88` und `98556c5`; CI-Lauf 675 grün.
- Lauf 674 war rot: Die Pflichtanalyse fand, dass U15 `evaluateExtrusion` auf 161 Zeilen
  (gelistet 156) und `inspectWindow` über 80 Zeilen bzw. Komplexität 30 (gelistet 28) gehoben
  hatte.
- `98556c5` bringt beide Werte zurück. Der neue Code heißt deshalb `needs-target`.

## Anlass

- Bei seiner Prüfung von L02 sah der Nutzer in der Fehlerkarte „Blocked by failed input 3“ und in
  der Statuszeile „Modell r0 hat Fehler“.
- Ursache: Fehlerkarte und Baum-Tooltip zeigten die technische englische Meldung der Auswertung.
  Davon gibt es 113 Stellen, 77 davon ohne Code. Eine deutsche Erklärung gab es nur für Codes in
  abgelehnten Befehlen.
- Erster Schritt (`f361b2c`): Die Karte erklärt blockierte Schritte auf Deutsch, und die
  Statuszeile zeigt keine Revisionsnummern mehr.

## Änderung

- **`src/desktop/FeatureIssueText.cpp`:**
  - eine Tabelle Code → deutscher Text mit 49 Codes; sie ersetzt die bisherige `if`-Kette
    `booleanFailureText`;
  - `issueExplanation` liefert die Erklärung des Codes oder den allgemeinen Satz „Dieser Schritt
    lässt sich nicht berechnen.“, jeweils mit der technischen Meldung in Klammern.
- **Neue Codes für die häufigsten Fehler ohne Code:** `sketch-unsolved`,
  `sketch-support-missing`, `sketch-support-unsolved`, `sketch-plane-missing`,
  `sketch-needs-repair`, `end-face-missing`, `end-face-not-parallel`, `end-face-behind`,
  `profile-face-missing`, `profile-invalid`, `body-missing`, `base-body-exists`,
  `needs-target`.
  - Die technischen Meldungen bleiben unverändert. Protokolle, MCP und Assistent sehen dieselben
    Texte wie bisher, dazu den genaueren Code.
- **`FeatureRuntimeState::code`** reicht den Code an die Oberfläche durch.
- **Wo die deutschen Texte jetzt erscheinen:**
  - Fehlerkarte; bei blockierten Schritten ein Satz mit der Ursache;
  - Tooltip im Modellbaum;
  - Rückmeldung abgelehnter Befehle.
- **Funktionsgrenzen:** Der Listeneintrag `booleanFailureText` (Komplexität 24) entfällt; die
  Ausnahmeliste hat jetzt 541 Einträge.

## Grenzen

- 51 seltene, innere Fehler ohne Code bekommen den allgemeinen Satz, zum Beispiel „Contour
  builder did not supply an edge“. Ihr technischer Text bleibt in Klammern sichtbar.
- Kommt später ein neuer Code dazu, fordert der Test einen Text erst, wenn der Code in seine
  Liste aufgenommen wird.
