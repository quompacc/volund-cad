# R08 – Gesamtabnahme der abgeleiteten Regionen

19.09.2026. Teilung gemäß Implementierungsplan:
- [R08a](R08a.md): analytische Schnittbildung und Quellparameterintervalle.
- [R08b](R08b.md): orientierte Zellränder und Containment mit Innenkonturen.

Zwei konzentrische Kreise liefern einen Ring und eine getrennt auswählbare
Innenregion. Das Ergebnis trifft keine Benutzerauswahl. Drei geschachtelte Kreise,
Linie/Kreis, gekreuzte Kreise und Selbstschnitt werden deterministisch zerlegt.
Gemeinsame abgeleitete Grenzen bleiben auf dasselbe Quellintervall rückführbar.
Überlappende Quellkanten, unklare Tangentialkontakte und offene Grenzen werden
ausdrücklich diagnostiziert.

Der Vertrag liefert abgeleitete Regionen, keine persistente RegionId und keine
umgestellte produktive Extrusion. Diese folgen R09/R10. A-REG-01 insgesamt
bleibt bis zur produktiven Face-/Innenwire-Abnahme in R10 offen.
Prüfergebnisse stehen im R08b-Nachweis und dessen final-verification.txt.
