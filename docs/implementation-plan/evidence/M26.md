# M26 – Wendel (Helix)

**Status:** abgenommen am 14.10.2026 nach grünem CI-Lauf 593 (`82d80b6`).

## Entscheidungen (ohne Rückfrage, Nutzerauftrag vom 14.10.2026)

- **Die Wendel ist ein Drehen mit Steigung:** `RevolveParameters::pitch`.
  - Achse wie beim Drehen (M20): Skizzenlinie, Grund- oder Bezugsachse.
  - `angle` ist die ganze Drehung, bis 1000 Umdrehungen; Höhe = Steigung · Umdrehungen.
  - „Entgegen“ heißt linksgängig. Symmetrisch gibt es nicht.
  - Ergebnis und Zielkörper wie bei der Extrusion; benannt wird „Wendel N“.
- **Pfad:** Eine Schraubenlinie auf dem Zylinder um die Achse durch die Profilmitte, beginnend
  dort. Das Profil behält seine Lage zur Achse (Binormalen-Modus von
  `BRepOffsetAPI_MakePipeShell`), wie bei einer Feder oder einem Gewinde.
- **Profil:** genau ein Bereich ohne Loch (`helix-one-region`). Das Profil darf nicht auf der
  Achse liegen.
- **Flächennamen:** Anfang, Ende und die Seitenflächen jeder Konturkante.
- **Bedienung:**
  - `solid.create.helix` öffnet das Drehen-Panel im Wendel-Modus.
  - Statt des Winkels gibt es „Steigung“ und „Höhe“; bei einer neuen Steigung bleibt die
    Höhe.
  - Richtung: „Rechtsgängig“ oder „Linksgängig“.
  - Vorgabe: Steigung 5, Höhe 20.
- **Schema 28:** die Steigung als Kind 3 der Drehung.

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Kreis Ø2 im Abstand 10, Steigung 5, Höhe 20: rechts- und linksgängig innerhalb 1 % von 2π²·r²·R·n = 80π² | `application.helix` |
| Speichern/Öffnen, Rückgängig | ebenda |
| Abziehen von einem Zylinder R10 als Gewindenut (etwa die Hälfte der Feder) | ebenda |
| Oberfläche: Bereich wählen → Wendel (Vorschau innerhalb 1 %) → „Linksgängig“ angeboten → Höhe 10 halbiert → OK „Wendel 1“ → Rückgängig | `desktop.helix_panel` |

## Grenzen

- Keine kegelige Wendel, kein Normgewinde (Paketgrenze).
- Die Auswertung einer Wendel dauert einige Sekunden; Vorschau und OK warten darauf.
- Konturkanten des Ergebnisses werden nicht benannt.
