# G3 – mechanisches CAD v1: Gatebericht

**Ergebnis:** Das G3-Ziel ist erreicht, mit Paketlücke.

- Die mechanischen Referenzmodelle entstehen über die produktive Shell, lassen sich
  parametrisch ändern und als STEP austauschen.
- Offen bleibt ein G3-Paket: T05, das Verschmelzen koplanarer Flächen nach Drücken/Ziehen. Das
  Gate ist deshalb **nicht formal geschlossen**.
- G3 ist keine Plattform- oder Releasefreigabe; die L-Pakete bleiben Pflicht.

## Ziel (README)

Mehrkörpermodell, robuste Profile und Referenzen, Extrude/Pocket, Fillet/Chamfer, Hole,
Mirror/Pattern, Timeline, STEP, Maße. Definierter Funktionsumfang mit veröffentlichten Grenzen,
kein FreeCAD-Komplettheitsversprechen.

## Handbuch

[docs/handbuch.md](../../handbuch.md) nennt die umgesetzten Varianten und Grenzen.

Im v1-Umfang gibt es keine aktive Attrappe:

- Das Befehlsinventar gleicht jeden sichtbaren Befehl mit der Befehlstabelle ab.
- Es prüft, dass gesperrte Befehle nichts ändern.
- Die Oberflächentests lösen die Befehle über ihre echten Handler aus.

## Befehle

```
cmake --build --preset linux-desktop
ctest --preset linux-desktop -LE desktop -j4          # ohne Desktop
sh ~/bin/voelund-desktop.sh "desktop\."              # Desktop unter virtuellem Wayland
```

Dazu kommt die CI `ci / linux-desktop` auf `9ecd22c` (Lauf 636). Fedora lokal: 134/134 ohne Desktop, 71/71 Desktop; Windows: 134/134 ohne Desktop.

## Grenzen

- T05 offen: Nach Drücken/Ziehen bleiben koplanare Flächen getrennt.
- A-PART-02: Die Radiusänderung ist im Kern geprüft, nicht eigens in der Shell durchgeklickt.
- Die einzelnen Paketgrenzen stehen gesammelt im Handbuch.
