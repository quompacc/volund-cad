**Status:** teilweise, in Arbeit (23.10.2026). Abnahme nach grünem CI-Lauf.

## Entscheidungen (Agent, 23.10.2026)

- **Boxauswahl im 3D-Bereich** (außerhalb einer Skizze): Ein Zug aus dem Leeren wählt Körper.
  - Links→rechts ist ein Fenster (ganz innen), rechts→links kreuzend (berührt).
  - Mehrere Körper werden eine Gruppe (N02b). Die Statuszeile sagt „N Körper gewählt“.
  - Strg nimmt hinzu, eine leere Box hebt die Auswahl auf.
  - Ein Klick ohne Zug bleibt ein Klick ins Leere.
  - Maßstab ist die Hülle des Körpers auf dem Bildschirm.
  - Bei offenem Werkzeug geschieht nichts.
- **Kante vor Fläche** gab es schon: Nahe einer Kante gewinnt die Kante.
- **Noch nicht:**
  - Klick-Zyklus am selben Ort.
  - Tangentialkette per Doppelklick.
  - Auswahlfilter.
  - Box mit der Eingabe eines offenen Werkzeugs (etwa Kanten fürs Verrunden).
