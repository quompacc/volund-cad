# S04a – Sichtbare Fangmarker, Beziehungsvorschau und Rechteck aus dem Mittelpunkt

**Status:** abgenommen am 04.10.2026. Nutzerwunsch nach U13: Fangpunkte gelten für jedes
Werkzeug, wie in jedem CAD-Programm.

## Umsetzung

- **`SketchEditorInteraction::snapFeedback`:**
  - Liefert für jedes Zeichenwerkzeug die Fangpunkte in Cursornähe, den Punkt, auf den
    der Cursor gerade fängt, und die Beziehung, die ein Klick erzeugen würde.
  - Die Fanglogik ist dieselbe wie beim Klick: Endpunkte, Mittel- und Zentrumspunkte,
    Ursprung, Achsen, projizierte Punkte, „auf Objekt“.
  - Im Werkzeug „Auswählen“ gibt es keine Marker.
- **`SketchSnapOverlay`:**
  - Eine durchsichtige Qt-Ebene über dem Viewport zeichnet nahe Fangpunkte als Ringe und
    den aktiven Punkt als Punkt in der Akzentfarbe.
  - Am Cursor steht die Beziehung, z. B. Ursprung, Deckungsgleich, Waagrecht, Senkrecht,
    Auf Objekt, Tangential, Konzentrisch.
  - Qt zeichnet die Ebene, deshalb ist sie unabhängig von den unter Windows fehlenden
    OCCT-Schriften.
- **Strg** hält das Fangen an Punkten, Achsen und Objekten aus; das 1-mm-Raster bleibt.
- **Rechteck aus dem Mittelpunkt** (`sketch.tool.center_rectangle`, Umschalt+R):
  - Der erste Klick setzt den Mittelpunkt, der zweite eine Ecke. Die Vorschau zeigt das
    ganze Rechteck.
  - Zwei Konstruktionslinien binden den Mittelpunkt an die Diagonale (Diagonale und halbe
    Diagonale mit Mittelpunkt-Beziehung).
  - Der gefangene Punkt, z. B. der Ursprung, wird an den Anfang der halben Diagonale
    gebunden. So bleibt das Rechteck nach Maßänderungen zentriert.

## Grenzen

- Die fachlichen Korrekturen an Fangen und automatischen Beziehungen (doppelte Bedingungen,
  Rollen von Bogenpunkten) bleiben S04/S05.
- Marker erscheinen für Punkte. Eine Hervorhebung ganzer Kanten beim Fangen „auf Objekt“
  gibt es noch nicht.
