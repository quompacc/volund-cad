# M19 – Bezugsebene und Bezugsachse

**Status:** umgesetzt am 14.10.2026; Abnahme nach grünem CI-Lauf.

## Entscheidungen (ohne Rückfrage, Nutzerauftrag vom 14.10.2026)

- **Bezugsebene:**
  - Bezug ist eine Grundebene (XY/XZ/YZ) oder eine ebene Körperfläche.
  - Der Abstand gilt entlang der Normalen. Wahlweise wird die Ebene vorher um die X- oder
    Y-Achse ihres Bezugsrahmens gedreht (bis ±180°).
  - Ohne Auswahl ist XY der Bezug.
- **Bezugsachse:**
  - Eine Grundachse (X/Y/Z) oder eine Körperkante.
  - Eine gerade Kante ergibt die Achse auf der Kante. Bei einer Kreiskante geht die Achse
    durch den Mittelpunkt, senkrecht zum Kreis. Das ersetzt die im Plan genannte
    „Achse einer Zylinderfläche“.
  - Eine vorher angeklickte Kante wird beim Befehl sofort zur Achse, sonst wählt man im
    Panel eine Grundachse.
- **Keine Körperzugehörigkeit:**
  - Ebenen und Achsen gehören zu keinem Körper. Im Baum stehen sie außerhalb der Körper.
  - Gespeichert wird jede in einer eigenen Gruppe unter ihrer ID.
  - Im Viewport erscheinen sie in Bernstein und lassen sich anklicken. Ein Körper hinter
    einer Ebene gewinnt den Klick, wie bei den Grundebenen.
- **Skizze auf einer Bezugsebene:**
  - Sie verhält sich wie eine Skizze auf einer Grundebene: kein Stützkörper, sie öffnet
    einen eigenen Körper, und ihre Extrusion ist „Neuer Körper“.
  - Ihre Ebene folgt der Bezugsebene bei jeder Neuberechnung
    (`SketchParameters::constructionPlane`).
- **Schema 19.**

## Änderung

- **Dokument:** `FeatureKind::datumPlane/datumAxis`, `DatumPlaneParameters`,
  `DatumAxisParameters`, `SketchParameters::constructionPlane`.
  - Prüfungen: Es gibt genau einen Bezug. Die Fläche oder Kante gehört zu einem Körper des
    Dokuments. Die Skizze nennt eine frühere Bezugsebene.
- **Codec:** `NativeSolidFeatures.cpp` speichert Ebene und Achse. Die Skizze speichert
  ihre Bezugsebene als Kind 15. Schema 1–18 bleiben lesbar.
- **Auswertung** (`DatumEvaluation.cpp`):
  - Der Rahmen (`EvaluatedFeature::datumFrame`) entsteht aus Grundebene oder benannter
    Fläche (`supportFaceFrames`), aus der Grundachse oder der benannten Kante
    (`filletEdgeShapes`).
  - Fehlt die Fläche oder Kante, kommt der Fehler `datum-reference-missing`. Eine Kante, die
    weder gerade noch ein Kreis ist, ergibt `datum-axis-edge`.
  - Die Skizzenauswertung setzt die Ebene aus dem Rahmen. Die Abhängigkeiten führen Ebene →
    Skizze und Körper → Ebene/Achse.
- **Anwendung:**
  - Aktionen `CreateDatumPlaneAction`, `EditDatumPlaneParametersAction`,
    `CreateDatumAxisAction`, `EditDatumAxisParametersAction`.
  - `CadSession::createDatumPlane` („Bezugsebene N“), `createDatumAxis`
    („Bezugsachse N“), `datumFrame`.
  - Der Skizzeneditor startet auf einer Bezugsebene und öffnet eine solche Skizze wieder.
    Auch ein Entwurf wird wiederhergestellt.
  - MCP-Ergebnis.
- **Viewport:** `SceneDatum`, `setDatums`, `setDatumSelectionHandler`,
  `DatumPresentation`.
- **Oberfläche:**
  - `DatumToolController` mit den Feldern Abstand, „Drehen um“ und Winkel bzw. Achse X/Y/Z.
    Die Vorschau zeigt die Ebene.
  - Befehle `solid.create.datum_plane` und `solid.create.datum_axis`.
  - „Skizze“ gilt auf einer gewählten Bezugsebene. „Bearbeiten“ und die Timeline öffnen das
    Panel wieder.
  - Symbole und Fehlertexte.

## Grenzen

- Keine Ebene durch drei Punkte, nicht tangential, kein Bezugskoordinatensystem
  (Paketgrenze).
- Achsen auf Kanten haben keine Werte zum Bearbeiten. Sie folgen ihrer Kante.
- Ebenen und Achsen lassen sich noch nicht einzeln ausblenden.
