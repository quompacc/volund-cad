# T03 – Startversatz und Extrusion bis Fläche

**Status:** abgenommen am 06.10.2026 nach grünem CI-Lauf 428 (`9c08320`). Der Nutzer hat
die Aufnahme des Panels gesehen („passt so“). Damit ist Block A (T01–T03) abgeschlossen.
Teilplan: [T-plan.md](../T-plan.md).

## Änderung

- **Dokument:** `ExtrusionParameters` hat zwei neue Angaben.
  - `offset`: Längenmaß, auch negativ, an Parameter bindbar wie die Distanz.
  - `upToFace`: dokumentinterne Flächenreferenz aus Körper und semantischer Herkunft wie
    in T01. Sie hat keine Dokument-ID und muss deshalb beim Duplizieren nicht umgeschrieben
    werden.
- **Natives Schema 9:**
  - Optionale Kindknoten 7–9; ältere Leser lehnen sie ab.
  - Die Kodierung der Herkunft teilt sich `upToFace` mit der Skizzenbindung
    (`writeNativeSubshapeOrigin`).
- **Auswertung:**
  - Die Skizze wird um den Versatz entlang der Extrusionsrichtung verschoben.
  - „Bis Fläche“ endet auf einer parallelen ebenen Fläche des genannten Körpers, so wie
    das letzte frühere Feature ihn hinterlassen hat. Das ist eine explizite Abhängigkeit
    (`bodyProducerBefore`); die Extrusion folgt der Fläche.
  - Eine Fläche hinter dem Start oder schräg zur Skizze ist ein Fehler.
  - Das Referenzprisma übernimmt die aktuelle Länge, weil Referenzergebnisse unplatzierte
    Grundkörper sind.
- **Parameter:** Ein gebundener Versatz wird gespiegelt, zählt als Verwendung und wird
  beim Löschen gelöst. `bind_extrusion_distance` nimmt `length: "offset"`.
- **Panel:**
  - Neue Felder „Versatz“ und „Ende“ (Distanz / Bis Fläche).
  - Bei „Bis Fläche“ ist die Distanz gesperrt; OK wartet auf eine im Viewport
    angeklickte Fläche. Der Klick geht an das Werkzeug.
  - Die Felder eines beendeten Panels werden sofort ausgeblendet.
  - Gesperrte Eingaben sind ausgegraut.
- **MCP:** `offset` und `upToFace` (`supportId` + `face`) an beiden Extrusionswerkzeugen;
  der Kontext nennt beides.

## Grenzen

- „Bis Fläche“ nur für ebene, zur Skizze parallele Flächen mit eindeutiger Herkunft.
  Mantelflächen von Extrusionen und Böden haben noch keine stabile Herkunft.
- Versatz und Ende lassen sich noch nicht in der Eigenschaftenkarte einer bestehenden
  Extrusion ändern (über die Aktionsschicht schon).
