# S17 – Kanten bewusst in die Skizze projizieren

**Status:** umgesetzt am 14.10.2026; Abnahme nach grünem CI-Lauf.

## Entscheidungen (ohne Rückfrage, Nutzerauftrag vom 14.10.2026)

- **Bezug einer Projektion:** Element, Körper und Kante als Flächenpaar (`FilletEdge`, wie
  bei Verrundung und Fase). So bleibt sie über Neuberechnungen benannt.
- **Projiziertes Element:**
  - Es ist immer Konstruktionsgeometrie und begrenzt keinen Bereich.
  - Im Löser ist es fest. Gezeichnete Geometrie, die daran hängt, folgt ihm.
  - Stutzen, Verlängern, Teilen und Verrunden weisen es ab.
  - Löschen des Elements entfernt die Projektion.
- **Quelle:** Maßgebend ist der Körper, wie er vor der Skizze in der Historie steht. Spätere
  Features wirken nicht zurück.
- **Bedienung:**
  - `sketch.project` (Gruppe „Bearbeiten“) schaltet die Kantenwahl an und aus.
  - Jeder Klick auf eine Körperkante projiziert sie.
  - Ein Werkzeugwechsel oder das Ende der Skizze beendet das Projizieren.
- **Schema 23.**

## Änderung

- **Dokument:**
  - `SketchProjection` in `SketchParameters::projections`, mit Prüfung.
  - Abhängigkeit der Skizze vom Erzeuger des Körpers.
  - Codec: Kind 16 der Skizze, gelesen ab Schema 23.
- **Auswertung:**
  - `projectSketchEdge` macht aus einer geraden Kante eine Linie und aus einem Kreis oder
    Bogen parallel zur Ebene einen Kreis oder Bogen. Andere Kanten werden abgewiesen.
  - `refreshSketchProjections` setzt die Geometrie vor dem Lösen.
  - Fehler sind `projection-missing` und `projection-unsupported`, jeweils mit dem Element.
- **Editor:**
  - `projectEdge` ist ein Rückgängig-Schritt und weist eine doppelte Kante ab.
  - Beim Öffnen einer Skizze zeigt der Editor die aktuelle Lage der Kante
    (`CadSession::evaluatedSketch`).
- **Viewport:** Im Skizzenmodus mit Kantenwahl nimmt ein Klick nur Körperkanten, auch unter
  einer schon projizierten Linie.

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Obere Boxkante projiziert: Konstruktionslinie der Kantenlänge | `application.sketch_projections` |
| Gleiche Kante doppelt, Kante quer zur Ebene, Teilen: abgewiesen | ebenda |
| Rückgängig/Wiederholen mit Projektion | ebenda |
| Gezeichnete Linie deckungsgleich am Projektionsanfang; die Projektion bleibt fest | ebenda |
| Box breiter: Projektion und angehängte Linie folgen | ebenda |
| Erneutes Öffnen zeigt die aktuelle Kante; Löschen entfernt die Projektion | ebenda |
| Speichern/Öffnen | ebenda |
| Quelle (Extrusion) scheitert: Skizze „blocked-by-dependency“ | ebenda |
| Kante fehlt: `projection-missing` an Skizze und Element | ebenda |
| Oberfläche: Skizze auf XY → Projizieren → zwei Kanten nacheinander, erneuter Klick auf die erste (unter ihrer Projektion) fügt nichts hinzu → OK | `desktop.sketch_project_flow` |

## Grenzen

- Keine Schnittkurven der Skizzenebene mit Körpern (Paketgrenze).
- Ellipsen aus schrägen Kreisen und Freiformkanten werden abgewiesen.
- MCP projiziert noch keine Kanten. `edit_sketch` geht von den gespeicherten Parametern aus
  und behält deshalb die Projektionen. Entfernt es ein projiziertes Element, weist die Prüfung
  die Änderung ab.
