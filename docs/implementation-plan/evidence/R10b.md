# R10b – Faces für Regionen schneidender Konturen

**Status:** abgenommen am 04.10.2026 nach grünem CI-Lauf 370.

## Umsetzung

- **Faces aus Randintervallen** (`src/features/SketchRegionIntervalFaces.*`):
  - Jede Zelle, deren Rand keine ganze geschlossene Schleife ist, entsteht direkt aus
    ihren R08b-Intervallen. Das gilt für geteilte Elemente ebenso wie für Verzweigungen an
    Ecken.
  - Jedes Intervall wird zu einer getrimmten Kante auf der Quellkurve des Elements. Die
    3D-Kurve trägt dieselben Parameter wie die ebene R08b-Kurve: bei Linien die Länge ab
    Startpunkt, bei Kegelschnitten den Winkel.
  - Benachbarte Intervalle teilen sich einen Eckpunkt, dessen Toleranz beide berechneten
    Kurvenenden umfasst. Fragmente eines Elements teilen sich dieselbe Kurve.
  - Jede Fläche liegt in der Skizzenebene. Sie wird mit BRepCheck geprüft, und ihr Inhalt
    muss der vorzeichenbehafteten Randfläche entsprechen, auf 1e-7 relativ genau.
- **Vereinigung benachbarter Zellen:**
  - Ein Intervall, das zwei gewählte Zellen gegenläufig begrenzen, hebt sich auf. Der Rest
    wird zu Schleifen verkettet.
  - An einem Punkt mit mehreren Fortsetzungen gilt dieselbe Regel wie beim Zellaufbau:
    die erste Fortsetzung im Uhrzeigersinn. Zellen, die sich nur in einem Punkt berühren
    (Bow-Tie), bleiben getrennte Flächen.
  - Löcher gehören zur kleinsten umgebenden Außenschleife.
- **R10-Weg unverändert:** Zellen, deren Ränder ganze Schleifen sind, laufen weiter über
  den bisherigen Weg. Bestehende Flächen und Referenzen von V01 bleiben damit gleich.
- **Kantenprovenienz je Intervall:**
  - `EvaluatedContourEdge` trägt für Fragmente Element, Rolle, Parameterbereich des
    Fragments und den ganzen Bereich des Elements (`domain`).
  - Die Extrusionsprovenienz bezieht sich auf das ganze Element auf derselben Kurve.
    `resolveEdgePoint` sucht das Fragment, das den Punkt enthält, und klemmt nichts
    zurecht.
  - Ein Kappenpunkt auf einer Sichel bleibt damit über Maßänderungen stabil, auch wenn
    sich die Schnittpunkte verschieben. Ein Punkt außerhalb des Fragments ergibt
    `parameterOutside`.

## Prüfungen (`features.sketch_region_faces`)

| Fall | Ergebnis |
|---|---|
| zwei Kreise r = 2, Abstand 2 | Linse 8π/3 − 2√3, Sichel 4π − Linse; Linse + Sichel = eine Scheibe 4π; alle drei = 8π − Linse |
| Sehne durch einen Kreis | jede Hälfte 2π, beide zusammen eine Scheibe 4π |
| Bow-Tie (Selbstschnitt) | Lappen je 1; beide gewählt: zwei getrennte Flächen |
| Rechteck mit Diagonale | Dreieck 4 aus geteilten Rechteckseiten |
| zwei Kreise in einem Ring R = 10 | Ring mit 2 Wires, 100π − (8π − Linse) |
| Kappenreferenz | Punkt bei t = 0,5 auf Kreis 1 der linken Sichel liegt bei (−2, 0, 5); t = 0 liegt in der Linse → `parameterOutside`; nach Verschieben von Kreis 2 bleiben RegionId und Punkt gleich |

Alle Fälle aus R10 (Rechteck, Line/Arc, Ellipse, Ringe, Permutation, Toleranzmatrix,
lokalisierte Fehler) bestehen weiterhin.

## Grenzen

- **Spiegelzellen bleiben per RegionId mehrdeutig.** Beispiele sind die beiden Hälften
  einer Sehne. Sie haben dieselbe R09-Signatur, und R09 löst sie bewusst nicht auf. Ihre
  Flächen entstehen korrekt (im Test direkt über `intervalRegionFaces` geprüft), eine
  Extrusion kann sie aber noch nicht per ID wählen.
  - Eine Unterscheidung über die Laufrichtung der Linie wurde geprüft und verworfen: Klappt
    der Löser eine Linie geometrisch um, zeigte eine alte ID still auf die andere Hälfte.
  - Das ist offen für eine Nutzerentscheidung.
- Berührende Zellen ergeben getrennte Flächen. Ob daraus getrennte Körper entstehen,
  entscheidet die Extrusion wie bisher.
