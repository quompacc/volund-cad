# U05 – Schwebendes Werkzeugpanel über den generischen ToolPanelHost

**Status:** abgenommen am 04.10.2026.

## Umsetzung

- **`FloatingCard`:**
  - Eine schwebende Karte rechts im Viewport unter dem ViewCube, mit Titel und
    scrollbarem Inhalt.
  - Die feste Fußzeile hält OK und Abbrechen immer sichtbar.
  - Die Höhe richtet sich nach dem Inhalt und endet nie unter dem Viewport.
- **`ToolPanelHost`:**
  - Statt eines Docks ist es jetzt eine `FloatingCard` (`activeToolPanel`) und besitzt
    weiter genau eine Sitzung.
  - Escape führt einen Schritt zurück bzw. bricht ab; Enter bestätigt wie OK, wenn das
    Werkzeug es erlaubt.
  - Die Werkzeugauswahl nutzt die volle Breite, die Aktionsreiter lassen sich blättern.
- **Eigenschaften:** `FeaturePropertiesPanel` liegt in einer zweiten Karte
  (`featurePropertiesCard`) am selben Platz. Sie ist nur sichtbar, wenn ein Feature
  gewählt und kein Werkzeug offen ist. Ihre Höhe folgt der sichtbaren Seite. Die Docks
  „Eigenschaften“ und „Werkzeug“ entfallen.
- **Werkzeugwechsel nach K04:**
  - Solange ein Skizzeneditor oder eine Extrusion offen ist, sperrt
    `ShellState::toolBlocksCommands()` Skizze, Extrudieren, Bearbeiten, Quader, Zylinder,
    Bewegen sowie Dokument-Rückgängig/Wiederholen.
  - Erst OK, Abbrechen oder Escape geben sie frei. So kann keine Skizze still verworfen
    werden, und Strg+Z gehört eindeutig dem offenen Werkzeug.

## Prüfungen

| Test | Inhalt |
|---|---|
| `desktop.tool_panel_lifecycle` (neu, A-UI-02 Extrude) | Karten schweben im Viewport; ohne Werkzeug zeigen sie die Eigenschaften; Start ersetzt sie durch das Panel; Parameteränderung und Abbrechen hinterlassen identischen Zustand (Stempel, geändert, Undo, Featurezahl); während des Werkzeugs sind Quader, Bearbeiten und Rückgängig gesperrt; Escape bricht ohne Änderung ab; OK legt genau eine Extrusion an, ein Rückgängig entfernt sie |
| `desktop.shell_state` | offene Skizze sperrt weitere Skizze und Dokument-Undo |
| `desktop.viewport_startup` | Eigenschaften und Panel teilen den schwebenden Platz |
| bestehende Skizzen-/Extrusionstests | laufen unverändert auf der schwebenden Karte |

## Grenzen

- Der Skizzeneditor zeigt seine Werkzeuge weiter im Panel. Die Verlagerung der
  Zeichenwerkzeuge in die Kontextleiste folgt mit S13.
- A-UI-02 für Fillet, Chamfer und Hole folgt mit diesen Werkzeugen (M-Pakete).
- Erweiterte Optionen zum Einklappen gibt es noch nicht, weil die heutigen Panels keine
  haben. Die Karte nimmt sie im Inhalt auf.
