# S18 – Referenzmaße (nicht treibend)

**Status:** abgenommen am 14.10.2026 nach grünem CI-Lauf 591 (`436be3a`).

## Entscheidungen (ohne Rückfrage, Nutzerauftrag vom 14.10.2026)

- **Referenz:** Jede Bemaßung kann Referenz sein: Länge, Radius, Durchmesser, Abstände
  (auch X/Y und Punkt–Linie) und Winkel. Ein Referenzmaß ist keine Gleichung im Löser. Nach
  jedem Lösen trägt es den gemessenen Wert.
- **Anlegen:** Ein Maß, das die Skizze überbestimmen würde (mehr widersprüchliche oder
  überflüssige Bedingungen als vorher), wird von selbst als Referenz angelegt.
- **Umschalten:**
  - `sketch.toggle_reference` (Gruppe „Bemaßungen“) wirkt auf das gewählte Maß und ist ein
    Rückgängig-Schritt.
  - Zurück auf treibend wird abgewiesen, wenn es überbestimmen würde. Das Maß bleibt dann
    Referenz.
- **Anzeige:** Ein Referenzmaß steht in Klammern. Sein Wert lässt sich nicht eingeben. Ein
  Klick auf das Label wählt es, damit man es zurückschalten kann.
- **Grenze:** Ein Referenzmaß ist nie an einen Parameter gebunden, ein gebundenes Maß bleibt
  treibend.
- **Schema 24.**

## Änderung

- **Dokument:**
  - `SketchConstraint::reference`, mit Prüfung (nur ungebundene Bemaßungen).
  - Ein Referenzwert darf 0 sein und ein Referenzwinkel 0° oder 180°.
  - Codec: Kind 10 der Bedingung, gelesen ab Schema 24.
- **Löser:** Er übergeht Referenzmaße. `measureReferenceDimensions` misst sie nach dem Lösen
  (`SketchReferenceDimensions.cpp`).
- **Editor:**
  - `toggleReference` und `isReferenceDimension`.
  - Beim Hinzufügen und Umschalten entscheidet die Zahl überbestimmender Bedingungen. Der
    Löser kann die Redundanz an einem anderen Maß der Gruppe melden.
- **Oberfläche:** Befehl, Symbol und Freigabe bei gewähltem Maß; Label in Klammern.
- **MCP:** Optionales Feld `reference` an Bemaßungen (nicht zusammen mit `parameterId`). Der
  Wert darf fehlen. Die Auswertung misst Referenzmaße auch in ungelösten Skizzen.

## Prüfungen

| Szenario | Nachweis |
|---|---|
| Abstand 10 treibend; als Referenz nicht eingebbar, in Klammern | `application.sketch_reference_dimensions` |
| X 15 und Y 8 treibend: Referenz zeigt 17 | ebenda |
| Zurück auf treibend würde überbestimmen: abgewiesen | ebenda |
| Gleicher Abstand noch einmal: von selbst Referenz, Löser erfolgreich | ebenda |
| Rückgängig | ebenda |
| Speichern/Öffnen | ebenda |
| Ohne Y-Maß wieder treibend, Linie bleibt 17 | ebenda |
| MCP: Referenzdurchmesser ohne Wert misst 20; gebunden abgewiesen | `mcp.tools` |
| Oberfläche: Linie 12 → Label anklicken → umschalten (Klammern) → treibend → Referenz → OK | `desktop.sketch_reference_flow` |

## Grenzen

- Referenzmaße sind nicht an Parameter bindbar (Paketgrenze).
